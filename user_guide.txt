YDL Studio v2.0.0 사용 가이드 (User Guide)
=============================================

YDL Studio는 yt-dlp와 FFmpeg를 기반으로 영상(MP4) 및 음원(MP3/FLAC/M4A)을 손쉽게 내려받을 수 있도록 돕는 Windows용 포터블 그래픽 인터페이스(GUI) 프로그램입니다.

1. 사전 준비 및 포터블 실행 안내
--------------------------------
- 단일 실행 파일(YDL-Studio-v2.0.0.exe)은 별도의 Python 설치 없이 바로 실행할 수 있습니다.
- 고화질 비디오/오디오 병합(1080p/4K) 및 음원 변환(MP3/FLAC)에는 FFmpeg가 사용됩니다. 시스템에 FFmpeg가 없는 경우, 첫 실행 시 자동으로 %LOCALAPPDATA%\YDLStudio\bin 폴더에 준비됩니다.
- 만약 방화벽 등으로 자동 준비가 실패할 경우, https://ffmpeg.org 에서 ffmpeg.exe와 ffprobe.exe를 내려받아 실행 파일과 같은 폴더에 넣어 주세요.

2. 3단계 빠른 사용법 (Zero-Click 워크플로우)
--------------------------------------------
1) 상단 모드 선택:
   - [🤖 스마트 자동 (기본값)]: 영상 링크는 최고 화질 MP4로, 음원 사이트 링크(YouTube Music, SoundCloud 등)는 MP3 320kbps로 자동 분류합니다.
   - 원하는 경우 [🎬 최고화질 영상], [🎵 최고음질 음원 (MP3 320k)], [🎼 무손실 음원 (FLAC)], [📺 1080p FHD 영상]으로 고정할 수 있습니다.
2) 주소 붙여넣기:
   - 웹 브라우저에서 주소를 복사한 뒤 프로그램에서 [📋 원클릭 복붙] 버튼을 누르거나 단축키 Ctrl+V를 입력합니다.
   - 여러 개의 주소를 줄바꿈이나 공백으로 한꺼번에 붙여넣어도 자동으로 나누어 큐에 등록됩니다.
3) 다운로드 및 재생:
   - 주소 분석이 끝나면 별도의 추가 클릭 없이 자동으로 다운로드가 시작됩니다.
   - 완료된 카드에서 [▶️ 바로 재생] 또는 [📂 폴더] 버튼을 눌러 파일을 바로 확인할 수 있습니다.

3. 주요 기능 및 고급 도구
-------------------------
- 유튜브 믹스(Mix/Radio) 정제: watch?v=...&list=RD... 형태의 주소에서 불필요한 라디오 목록 파라미터를 제거하고 해당 단일 영상만 빠르게 다운로드합니다.
- 다단계 스트림 탐색: 기본 yt-dlp 추출이 실패할 경우, 웹페이지 내 숨겨진 M3U8/MP4 스트림 스캔(DeepWebScanner) 및 로컬 Chrome/Edge 브라우저 세션(BrowserFetcher)을 순차적으로 시도합니다.
- 실시간 스트림 스니퍼 ([🌐 스트림 스니퍼]): 일반 분석으로 잡히지 않는 웹페이지의 경우, 내장 스니퍼 창에서 영상을 재생하여 네트워크의 .m3u8 / .mp4 주소를 직접 포착할 수 있습니다 (PC에 Chrome 또는 Edge 설치 필요).
- 브라우저 쿠키 연동 ([⚙️ 설정]): 성인 인증이나 로그인이 필요한 콘텐츠의 경우 설정에서 브라우저 쿠키를 선택할 수 있습니다. 단, Chrome/Edge가 실행 중일 때는 브라우저가 쿠키 DB를 잠그므로 창을 모두 닫거나 Firefox 쿠키 사용을 권장합니다.

4. 지원 범위 및 알려진 한계
---------------------------
- 음원 차트 브릿지(실험적 기능): 멜론, 스포티파이, 지니, 벅스, 애플뮤직 등의 트랙 주소는 DRM 서버를 직접 복호화하지 않으며, 공개된 곡 제목/아티스트 메타데이터를 바탕으로 유튜브 오디오를 검색하여 매칭합니다.
- 상용 DRM 미지원: 넷플릭스, 디즈니+ 등 Widevine/PlayReady DRM이 걸린 스트리밍 서비스나 외부 하드웨어 크롬캐스트 기기 내부 세션은 다운로드할 수 없습니다.
- 이용 책임 안내: 콘텐츠를 내려받기 전에 각 플랫폼의 서비스 이용약관과 저작권 법규를 반드시 확인하고 준수하시기 바랍니다.

---------------------------------------------------------------------
Quick English Summary
---------------------------------------------------------------------
1. Choose your preferred output mode in the top bar (Smart Auto, Best MP4, MP3 320k, FLAC, or 1080p MP4).
2. Copy one or more URLs and press Ctrl+V (or click the Paste button). Downloads queue and start automatically.
3. Use Settings (Gear icon) to change the download directory or configure browser cookies for login-protected pages.
